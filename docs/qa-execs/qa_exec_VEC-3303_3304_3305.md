## Endpoints de importación

| Módulo | Export | Import |
|---|---|---|
| Regiones | `GET /presupuestos/regiones/exportar-excel` | `POST /presupuestos/regiones/importar` |
| Subregiones | `GET /presupuestos/subregiones/exportar-excel` | `POST /presupuestos/subregiones/importar` |
| Bases | `GET /presupuestos/bases/exportar-excel` | `POST /presupuestos/bases/importar` |

**Campo de upload**: `archivo` (no `file`)
**Método de upload PS**: `curl.exe -F "archivo=@path/to/file.xlsx"`
**Respuesta éxito**: `{"ok":true}`
**Respuesta error**: `{"errores":[{sheet, fila, campo, mensaje}]}`

## Estructura de exports

### Regiones (`exportar-excel`)
- Una hoja única
- Filas: título, headers, luego grupos por período (▶ header, entidad×N, Total asignado)
- Columnas: Región | M.General | M.Preventivo | M.Correctivo | M.Gestoría | M.Vencimientos | Total Asig. | Distribuido | Disponible

### Subregiones (`exportar-excel`)
- Una hoja por Región (nombre hoja = nombre de la región)
- Mismo patrón de filas que Regiones

### Bases (`exportar-excel`)
- Una hoja por Subregión (nombre hoja = "Subregión: X  |  Región: Y")
- Fila título muestra subregión y región
- Columnas: Base | M.General | ... | Total Asig. | Comprometido | Consumido | Saldo
- El ▶ header incluye "| Presupuesto disponible: $X" al final (información extra)

## Comportamiento del importador

- **Atómico**: si alguna fila tiene error, nada se guarda
- **Por período**: cada grupo de filas entre ▶ headers se valida y guarda por separado (dentro de la misma transacción)
- **Salto de fila vacía**: `celdaA === ''` → skip silencioso (útil para excluir filas de entidades sin presupuesto)
- **Validación distribución**: Subregiones y Bases comprueban `totalEnArchivo + totalHermanos ≤ presupuestoPadre`; Regiones NO (no tienen padre)
- **Exclusividad**: `monto_general > 0` XOR cualquier monto particular > 0

## Prerrequisitos para regresión

1. Crear config: `POST /api/periodo-configs {"nombre":"QA-PP-2026","fecha_inicio":"2026-01-01","frecuencia":"mensual","duracion":12}`
2. Setear REGIÓN DEFAULT P1: importar con `B4=200000` en export de regiones
3. Setear SUBREGIÓN DEFAULT P1: importar con `B4=100000` en export de subregiones (hoja "REGIÓN DEFAULT")
4. Bases: usar import sin ADELAIDE (limpiar A cells de filas ADELAIDE: `InnerXml = ""` + RemoveAttribute("t"))

## Gotcha: ADELAIDE

- Base `id=2`, `activa=false`, sin registros de presupuesto (inactiva al crear config)
- El export la incluye igual → importar sin modificar falla con "No se encontró presupuesto para 'ADELAIDE'"
- Solución: limpiar la celda A de cada fila ADELAIDE en el xlsx antes de importar
- Técnica XML: `$aCell.InnerXml = ""` + `$aCell.RemoveAttribute("t")` (no usar `RemoveChild` que falla con namespace)
- Filas ADELAIDE en el xlsx: 4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 44, 48 (patrón: 4 + (período-1)×4)

## Gotcha: modificar xlsx en PS 5.1

- `ZipArchiveMode::Update` no está disponible → usar Extract+Modify+Rezip
- `SelectSingleNode("v")` falla con namespace default → usar `InnerXml = ""`
- `ByteArrayContent($byteArray)` falla (aplana el array) → usar `curl.exe -F` para uploads
